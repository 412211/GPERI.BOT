# GPERI.BOT – College Inquiry Chatbot

## Overview

GPERI.BOT is a web-based college inquiry chatbot developed using Python and Django. The chatbot is designed to help students quickly access college-related information such as admissions, departments, courses, facilities, contact details, and other frequently asked questions through an easy-to-use web interface.

## Features

- Instant responses to common college-related queries
- User-friendly and responsive interface
- Django-based backend
- Easy to customize with new questions and answers
- Simple and lightweight design
- Secure login and registration system

## Tech Stack

- Python
- Django
- HTML
- CSS
- Bootstrap
- JavaScript
- SQLite

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/GPERI.BOT.git
```

### 2. Navigate to the project folder

```bash
cd GPERI.BOT
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Django server

```bash
python manage.py runserver
```

### 5. Open your browser

```
http://127.0.0.1:8000/
```
