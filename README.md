# GPT.Bot – College Inquiry Chatbot

## Overview

GPT.Bot is a web-based college inquiry chatbot developed using Django. The chatbot helps students quickly find information about the college, such as admissions, courses, departments, facilities, and other common queries. It provides a simple and user-friendly interface for accessing information without manually searching through the website.

## Features

* Student inquiry chatbot
* Instant responses to common college-related questions
* Simple and responsive user interface
* Django-based backend
* Easy to customize with new questions and answers

## Tech Stack

* Python
* Django
* HTML
* CSS
* Bootstrap
* JavaScript
* SQLite

## Project Structure

* Backend developed using Django
* Frontend built with HTML, CSS, Bootstrap, and JavaScript
* SQLite database for storing application data

## Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/gperi.bot.git
```

2. Navigate to the project:

```bash
cd gperi.bot
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the development server:

```bash
python manage.py runserver
```

5. Open your browser and visit:

```
http://127.0.0.1:8000/
```
